## Technical Readiness Checklist

**Work with your group. Help each other solve problems first.**

### Accounts and tools

□ GitHub account works
□ Git is installed
□ VS Code is installed
□ Python is installed
□ draw.io works

### Git check

Open a terminal and run:

```bash
git --version
```

Check configuration:

```bash
git config --global user.name
git config --global user.email
```

If either is missing, configure it.

### Python check

Run:

```bash
python --version
```

or, if needed:

```bash
py --version
```

### VS Code

□ Python extension installed
□ Jupyter extension installed
□ VS Code detects a Python interpreter

### Jupyter notebook

Create or open a `.ipynb` notebook.

Run:

```python
print("Jupyter works")
```

□ Cell runs successfully

### Required Python libraries

Run:

```python
import numpy
import pandas
import matplotlib
import sklearn

print("Python environment OK")
```

□ All imports work without errors

### Group check

□ Everyone has at least one working Python/Jupyter environment
□ Everyone can access GitHub
□ Group members can help each other with basic setup problems
□ Group can create and edit a shared draw.io diagram

### If something does not work

1. Ask your group first.
2. Identify exactly what fails.
3. Write down the error message.
4. Ask the teacher if the group cannot solve it.

### Minimum goal for today

Before leaving this activity, you should have:

□ access to course materials
□ working Python
□ working Jupyter notebook
□ required Python libraries
□ Git/GitHub access
□ working draw.io

**Do not spend the whole session perfecting your setup. The goal is a working environment.**
