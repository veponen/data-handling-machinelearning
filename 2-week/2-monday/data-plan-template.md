# Project Data Plan

Complete this with your group during Monday 2. (postponed, do before monday 3. Do before other tasks.)

Keep the answers short. The purpose is to decide **what data you need and what must happen before modelling**.

## 1. Problem

What are you trying to find out?

> Write the project question in one or two sentences.

## 2. Unit of Analysis

What should one observation represent?

Examples:

* one student;
* one quiz attempt;
* one task attempt;
* one student-week.

## 3. Data Sources

Which Edge-LMS data sources or files may be useful?

List the main sources.

## 4. Variables

Which variables may be useful?

For each important variable, note whether it is:

* directly stored;
* derived;
* inferred.

## 5. Relationships

How will the datasets be connected?

Identify the main keys and any one-to-many relationships.

## 6. Data Problems

What problems may need attention?

Consider:

* missing values;
* duplicates;
* inconsistent values;
* timestamps;
* unclear meanings;
* privacy;
* possible data leakage.

## 7. Data Gap

Is some useful information missing from the available Edge-LMS data?

If yes:

* Can it be derived from existing data?
* Could it be recorded automatically with current functionality?
* Would Edge-LMS need a new feature?

Any new data collection should:

* have a clear purpose;
* happen automatically during normal use;
* not create routine extra work for students or teachers.

Briefly describe the proposed data and how it would help the project.

## 8. Next Step

What should your group investigate or prepare first?

> State the next concrete action.
